# VoltGear Gaming Store

React + Vite + Tailwind CSS asosida tayyorlangan gaming PC va aksessuarlar do‘koni.

## Ishga tushirish
1. Node.js o‘rnating.
2. VS Code’da shu papkani oching.
3. Terminalda:
   ```bash
   npm.cmd install
   npm.cmd run dev
   ```
4. Terminal ko‘rsatgan `http://localhost:5173/` manzilini oching.

## Imkoniyatlar
- Gaming PC va aksessuarlar katalogi
- Kategoriya filtrlari va qidiruv
- Savatchaga qo‘shish, miqdorni o‘zgartirish va o‘chirish
- Demo buyurtma oynasi
- Yangi mahsulotlar bo‘limi
- Biz bilan bog‘lanish formasi
- Responsive dizayn

Eslatma: Bu demo loyiha. To‘lov, buyurtma serveri va kontakt forma backendga ulanmagan. Mahsulot suratlari internet orqali Unsplash’dan yuklanadi.
